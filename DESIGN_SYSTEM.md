# نور العلم — Brand identity v2

## Wordmark

A typographic, uninterrupted Arabic «نور العلم» set in Amiri bold, paired with a small light diamond and restrained `NOOR AL-ILM` Latin signature. The Arabic wordmark is one line in the header to avoid collisions in narrow widths. The logo has no mosque silhouette, human depiction or institutional emblem. Text remains selectable and vector rendered by the browser.

Neutral ivory and emerald carry the interface. Gold is reserved for reference points and numerals; red marks only the infographic serial and alerts. No muddy olive, false historical imagery or imagined religious portraits.

## Type and layout

- Arabic interface and long reading: IBM Plex Sans Arabic; editorial headings/wordmark: Amiri; Latin metadata: Inter.
- 16px base body with generous 1.7 line height, larger reading body for Arabic excerpts, fluid headings, 12-column desktop rhythm and stacked mobile layout.
- The current fonts are served by Google Fonts. Before a public production launch, self-host licensed files and test fallback metrics across Arabic, Urdu, Bengali, Hindi and Chinese.
- Semantic headings, visible controls, RTL flow, reduced motion and touch target spacing are design rules; a full assistive-technology audit remains open.

## Infographic template

Each draft design uses browser-rendered Arabic text, a unique NAI ID, red circular serial, brand line, low-opacity central watermark behind text, source metadata, QR to `/verify/:id`, draft version and review warning. It is a review preview, not an approved downloadable image. A released system needs a fixed render hash, final-version proofreading, corrections log and export QA.
